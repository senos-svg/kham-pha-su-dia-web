KHÁM PHÁ SỬ ĐỊA - BẢN HTML/CSS/JS

1. Giải nén ZIP.
2. Mở index.html bằng Chrome/Edge/Safari (không cần cài Python).
3. Tài khoản giáo viên demo: admin / admin123.
4. Học sinh chọn Đăng ký, sau đó đăng nhập bằng tài khoản được cấp; mật khẩu mặc định 123456.
5. Dữ liệu lưu trong localStorage của trình duyệt. Giáo viên vào Sao lưu để xuất JSON thường xuyên.

Đã chuyển các nhóm tính năng chính: đăng ký/đăng nhập, học liệu, video YouTube, infographic, 4 dạng câu hỏi, chấm điểm và giải thích, tiến độ, quản trị bài học/câu hỏi/trò chơi/tài khoản, thống kê, nhập/xuất JSON.

KHÁC BIỆT QUAN TRỌNG SO VỚI FILE PYTHON:
- Python gốc chạy Google Colab + Google Drive + Gradio, lưu dữ liệu tập trung.
- Bản HTML/CSS/JS này chạy độc lập, lưu trong một trình duyệt. Không tự đồng bộ Google Drive, không chia sẻ dữ liệu giữa các máy, không có xác thực an toàn phía máy chủ.
- Không tự động chuyển dữ liệu Drive cũ; cần chuyển đổi riêng từ các JSON cũ nếu muốn dùng dữ liệu thực tế.
- Phù hợp chạy thử, trình diễn và sử dụng cá nhân; muốn triển khai lớp học nhiều thiết bị cần backend/database và cơ chế xác thực.
